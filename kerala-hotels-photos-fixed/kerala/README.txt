KERALA — District-wise Tourism Guide
====================================

HOW TO OPEN
1. Extract the ZIP file.
2. Open the KERALA_Tourism_Website folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.
4. Click any district card to open its individual guide.

WHAT IS INCLUDED
- Homepage with all 14 Kerala districts.
- 14 separate district pages.
- District-specific written content: introduction, places, food, activities, culture, lifestyle, livelihoods and travel tips.
- Searchable district cards.
- Responsive navigation and layouts for desktop, tablet and mobile.
- Previous/next district navigation.

TECHNOLOGY
HTML5, CSS3 and vanilla JavaScript. No backend, database, PHP or framework.

IMAGE NOTE — IMPORTANT
The site loads photographs from Wikimedia Commons (Special:FilePath URLs), chosen per district/place (hero, each attraction, culture, lifestyle) plus a shared Kerala food set. An internet connection is required to load them. Each photo keeps its own Creative Commons / public-domain licence; credit the author from the file page at commons.wikimedia.org/wiki/File:<name> if you republish. Some slots use a nearby/representative photo where no exact one was found (see CHANGES.txt). Image file names are in js/data.js under "images".

CUSTOMISATION
- District content and image URL pools: js/data.js
- Homepage behaviour: js/main.js
- District page rendering: js/district.js
- Styling: css/style.css
